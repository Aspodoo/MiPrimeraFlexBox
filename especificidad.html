¿Qué es el Nivel de Especificidad?

La especificidad es el algoritmo que usan los navegadores para decidir qué regla CSS aplicar si hay conflictos (es decir, cuando varias reglas apuntan al mismo elemento). Funciona como un sistema de puntuación: un ID pesa más que una clase, y una clase pesa más que una etiqueta HTML.

¿Cómo se estructura el CSS?

La sintaxis de CSS es el conjunto de reglas que define cómo se escriben los estilos. Se compone principalmente de un selector (que apunta al elemento HTML a estilizar) y un bloque de declaración entre llaves { }, el cual contiene propiedades y valores separados por dos puntos y cerrados con punto y coma.

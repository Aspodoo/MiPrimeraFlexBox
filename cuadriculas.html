¿Qué es el Box Model?

El Box Model o modelo de caja es un concepto fundamental de CSS que explica cómo se organizan y dimensionan los elementos dentro de una página web. En CSS, cada elemento HTML se representa como una caja compuesta por cuatro partes: contenido, relleno, borde y margen. Comprender este modelo permite controlar el tamaño de los elementos, sus espacios internos y externos, y la distribución de los componentes de una página web.
